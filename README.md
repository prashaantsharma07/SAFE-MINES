# SafeMines 🛰️
**Safer tomorrow, one step ahead.**

SafeMines is a minefield safety and governance application designed to help field officers identify, avoid, and stay informed about landmines and hazardous areas. It combines real-time data, GPS mapping, and smart alerts to ensure safety in high-risk zones.

## ✨ Key Features
* **Interactive Risk Maps:** Visualize hazardous zones and safe paths.
* **Real-time Hazard Alerts:** Get instant notifications when approaching dangerous areas.
* **AI Risk Assessment:** Subterranean sensor analysis for early hazard detection.
* **Offline First:** Full functionality in low-connectivity mine environments with background synchronization.
* **Emergency SOS:** One-tap emergency reporting with instant location broadcasting.

## 🛠️ Tech Stack
* **UI:** Jetpack Compose (Modern Glassmorphic Design)
* **Database:** Room (Local persistence)
* **Sync:** WorkManager & Custom Network Monitor
* **Architecture:** MVVM with Repository pattern

## 🚀 Getting Started
1. Clone the repository.
2. Open in Android Studio Hedgehog or newer.
3. Build and Run on an emulator or physical device.
